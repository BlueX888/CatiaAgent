## 生成/验证隔离

- 生成侧输入：原始或派生 PDF、`catia_inspect_drawing` 产出的证据 manifest。
- 生成侧禁止：`datasets/NIST/models/**`、`verification/**`、历史 CATPart、本目录的审查结论。
- 独立校验：重开磁盘上的交付件，用冻结期望测量；不使用建模进程自报的结果。

## 验收参考溯源

`tools/verify_case.py` 使用 `verification/<case>.json` 冻结的参考 SHA-256
核对 `--reference`。其他 STEP 可用于诊断比较，但未证明来源时验收结果为 FAIL。
如需使用重导出参考，先在验证侧对重导出 STEP 与冻结原始 STEP 运行
`catia_mcp.cad_support compare`，把完整输出通过 `--reference-equivalence`
传给验收脚本。比较结果须包含双方 SHA-256，且包围盒、缺失材料和多余材料检查
均在冻结容差内；交付物的比较容差会扣除参考之间已有的差异。两份参考在容差内
的比较不等于证明特征树、设计意图或小于容差的特征一致。

报告中的 `referenceProvenance` 表示本次使用的参考是否与冻结文件相同或有
几何等价证据；历史报告不自动回填。FTC-09 的派生图纸仍须独立审查；复杂件
改参结果应按构建报告区分全部检查与抽样检查。
