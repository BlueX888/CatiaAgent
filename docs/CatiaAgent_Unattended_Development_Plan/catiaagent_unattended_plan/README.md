# CatiaAgent 无人值守开发规划包

本包提供架构规划和执行输入，不包含已经实施的产品代码改造，也不代表任何任务或后台调度已经启动。

## 文件

| 文件 | 用途 |
|---|---|
| plan.md | 完整架构、33 张任务卡、验收门禁、源代码证据和回退规则 |
| tasks.json | 与正文同源的任务定义、依赖、允许改动范围和验收要求 |
| START_HERE.md | 可直接交给执行 AI 的启动指令 |
| execution_state.template.json | 初始状态模板，复制到实际运行目录后使用 |
| task-result.template.json | 每任务证据报告模板 |
| manifest.json | 包内文件摘要及范围信息 |

## 使用

将本包交给开发 AI，要求从 START_HERE.md 和 T00 开始。任务清单全部未执行。不要将模板 null 字段替换成假值；由实际运行发现并填写。

主线 T00 至 T29 共 30 项。T30 至 T32 共 3 项为条件扩展。独立的离线成果可以先交付，真实产品认证等待指定环境及证据。
