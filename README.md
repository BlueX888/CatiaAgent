# CatiaAgent

CATIA 建模智能体项目，包含 PilotDeck 集成和 CATIA V5 MCP 服务。

- [PilotDeck](PilotDeck/README.md)：智能体平台与 CATIA 集成。
- [CATIA V5 MCP server](catia-v5-mcp-server/README.md)：CATIA 工具服务和建模能力。
- [建模脚本与测试](datasets/nist-pdf-benchmark/)：PDF 建模工具与测试代码。

安装与运行方式请参考各目录的 README。数据集、运行结果、本地依赖和生成文件未包含在本仓库中；部分建模和测试需要自行准备数据及 CATIA 环境。两个组件保留各自的许可证和来源信息。

PilotDeck 的部分上游文档图片和视频未纳入，相关 README 的媒体链接可能无法显示。
